# 🚀 Atif Tech

> Production-Ready AI Powered Learning Management System (LMS)

## 📖 About

Atif Tech is a modern AI-powered Learning Management System developed by **Malik Atif Ali**. It provides a complete online education platform with secure authentication, enrollment management, AI-powered learning, and dedicated dashboards for Admin, Teachers, and Students.

## ✨ Features

- 🔐 Secure JWT Authentication
- 👨‍💼 Admin Dashboard
- 👨‍🏫 Teacher Dashboard
- 🎓 Student Dashboard
- 📝 Online Enrollment System
- 📚 Course Management
- 🎥 Video Lessons
- 📄 PDF Notes
- 🧠 Google Gemini AI Tutor
- 📝 Quizzes & Assignments
- 🏆 Certificate Generation
- 🔔 Notifications
- 🌐 English & Urdu Support
- 📊 Analytics Dashboard
- 🛡️ Role-Based Access Control
- ⚡ Production-Ready Architecture
